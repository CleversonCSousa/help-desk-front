# HelpDesk

O HelpDesk é um sistema de gerenciamento de chamados desenvolvido com o intuito de otimizar o fluxo de suporte técnico. 

Para demonstração do funcionamento do sistema, é necessário que o back-end esteja configurado, que se encontra com um guia de configuração no seguinte repositório: [HelpDesk Back-end](https://github.com/CleversonCSousa/help-desk-back)

## Rodando o projeto
1. **Clone o projeto**: `git clone https://github.com/CleversonCSousa/help-desk-front`
2. **Instale as dependências**: `npm install` (ou `yarn`)
3. **Configure as variáveis de ambiente**: 
   Configure a variável de ambiente `VITE_API_BASE_URL` (back-end url). Por padrão, configure como:
